# Murmur

Free voice dictation for macOS. Press a hotkey, speak, and cleaned-up text appears at your cursor — anywhere you can type.

A Wispr Flow / Superwhisper alternative. Local Whisper for transcription, Gemini's free tier for cleanup, $0 to run.
